# 图纸规范化：GB/T 50001-2017 规则整理与修改策略

> 依据：《房屋建筑制图统一标准》GB/T 50001-2017。本文仅**归纳摘要**与本项目图纸输出相关的条款（条文号注明），不复制标准原文；实施前以标准正式出版文本为准。关联 PROGRESS 需求：尺寸标注 [P0]、图纸字号标准化 [P1]、图层管理 [P1]、剖面图 [P1]、消隐 [P2]。

## 一、规则整理（与本图纸相关的条款）

### 1. 图幅与图框（第 3 章）

- 幅面 b×l：A4 = 210×297（横式：短边作垂直边）。A0~A3 宜横式使用。〔3.1.1/3.1.4〕
- 图框尺寸：装订边 a=25mm；A2~A4 的 c=5mm（A0/A1 为 10mm）。〔表 3.1.1〕
- 图框线用**粗实线**绘制；对中标志线宽 0.35mm、伸入图框内 5mm（画在各边中点）。〔3.1.1 注、3.1.2〕
- 需缩微的图纸：一边附 100mm 米制尺度（10mm 分格），四边附对中标志。〔3.1.2〕
- 一个工程不宜多于两种幅面。〔3.1.5〕

### 2. 标题栏（第 3.2 节）

- 标题栏位于图纸右下角，含：设计单位名称区、工程名称/图名区、签字区（实名列+签名列）、图号区等分区；尺寸与布局按标准图 3.2.2 选取。〔3.2.1/3.2.2〕
- 横式图纸标题栏在右下角；与图框的相对位置按标准附图。〔3.2.1〕

### 3. 图线（第 4 章）

- 基本线宽 b 从 **1.4 / 1.0 / 0.7 / 0.5mm** 系列选取；线宽组按「b / 0.5b / 0.25b」三档配套使用。〔4.0.1〕
- 图线类型：实线、虚线、**单点长画线**、双点长画线、折断线、波浪线。〔4.0.2〕
- 图框和标题栏线宽按表 4.0.4（图框线 > 标题栏外框线 > 分格线；缩微时不宜用 0.18mm 及更细线宽）。〔4.0.4 注〕
- 点画线两端不应为点；线段相交处应线段交接；虚线为实线延长线时不得相接。〔4.0.6~4.0.9〕
- 图线不得与文字符号重叠，冲突时优先保证文字清晰。〔4.0.10〕

### 4. 字体（第 5 章）

- 汉字：优先 TrueType **宋体**，矢量字体用**长仿宋**，宽高比 0.7；同一图纸字体不超过两种。〔5.0.3〕
- 字高系列：1.8 / 2.5 / 3.5 / 5 / 7 / 10 / 14 / 20mm（表 5.0.2）。
- 字母数字：Roman 字型，字高**不小于 2.5mm**〔5.0.7〕；斜体逆时针倾斜 75°。〔5.0.6〕

### 5. 比例（第 6 章）

- 比例注写在**图名右侧**，字高比图名小一号或二号，基准线取平。〔6.0.3〕
- 优先采用常用比例（1:1, 1:2, 1:5, 1:10, 1:20, 1:50, 1:100, 1:200 …表 6.0.4）。〔6.0.4〕
- 自选比例时应在适当位置绘制**比例尺**；需缩微的图纸应绘制比例尺。〔6.0.6〕

### 6. 定位轴线（第 8 章）—— 与「缝」直接相关

- 定位轴线用 **0.25b 单点长画线**（细点画线）绘制。〔8.0.1〕
- 编号注写在轴线端部的**圆内**：圆用 0.25b 实线，直径 8~10mm，圆心在轴线延长线上。〔8.0.2〕
- 编号规则：标注在图样下方及左侧（或四面）；**横向用阿拉伯数字，从左至右；竖向用大写英文字母，从下至上**（I、O、Z 不用）。〔8.0.3〕
- 附加轴线用分数形式编号；详图适用多根轴线时同时注明。〔8.0.6/8.0.7〕

### 7. 尺寸标注（第 11 章）

- 组成：尺寸界线 + 尺寸线 + 尺寸起止符号 + 尺寸数字；单位 mm，**不注写单位**。
- 起止符号为中粗斜短线，倾斜方向与尺寸界线成顺时针 45°，长 2~3mm。
- 尺寸宜标注在图样轮廓以外；多层尺寸：近图样者小，总尺寸在最外一道。
- 尺寸数字不得被图线穿过；无法避免时需将图线断开。

### 8. 投影法与图名（第 10 章）

- 第一角投影（正投影法）〔10.1〕——与本项目现有设置一致。
- 视图命名按工程惯例：正立面图、侧立面图、平面图等，图名下方**一粗一细双横线**，比例注于右侧（见 6.0.3）。

### 9. 计算机制图（第 12~14 章）

- CAD 文件命名、**图层**组织（第 13 章：图层命名与分类）、协同设计。
- 与 SVG/PDF 输出的对应：图层 = SVG 分组/PDF 分层，命名应遵循标准图层语义（轴线、轮廓、标注、图框、标题栏等）。

## 三、修改策略（分三阶段）

### Phase 1：图纸框架（对齐"外观合规"，先行）

1. A4 横式图框：幅面线 → c=5 边距 → a=25 装订边 → 粗实线图框 + 四边对中标志
2. 规范标题栏：右下角、分区结构（单位/图名/图号/日期/比例）、外框 0.7b、分格 0.35b；具体分区宽高参照标准图 3.2.2 简化设计（研究用图可精简签字区）
3. 字体基线：汉字宋体（reportlab 有内置 STSong），字高 snap 到2.5/3.5/5/7 系列；数字/代号 ≥2.5mm
4. 图名改造：每个视图加图名 + 双下划线（粗 0.7b + 细 0.35b），比例注图名右侧
5. 线宽组重构：选定 b=0.7mm（A4 幅面）→ 粗 0.7 / 中 0.35 / 细 0.18；构件可见轮廓 = 中粗，标注/图例 = 细

### Phase 2：标注体系（毕业条件 4 的核心短板，P0）

1. 尺寸标注引擎：尺寸线/界线/45° 起止符号/数字，mm 不带单位；多层排列（构件定位尺寸一道 + 总尺寸一道）
2. 定位轴线编号：缝编码 → 标准轴线编号映射（见决策点 A），平面图中横向数字/竖向字母，圆圈 8mm 0.25b
3. 数据来源：标注内容从 resolver 的 spec 推导（轴间距、柱高、柱径），不出现手工输入的标注数值

### Phase 3：细节与扩展

1. 轴线线型切换：虚线 → 单点长画线（dot-dash），0.25b
2. SVG/PDF 图层分组命名对齐标准语义（轴线/轮廓/标注/图框/标题栏）
3. 剖面图 + 剖切符号 + 材料图例（与 PROGRESS 剖面图 [P1] 合并实施）
4. 比例尺可视化去留：采用常用比例后可默认隐藏，仅自选比例/缩微需求时显示

### 决策点（A/B/C 已定案，D 暂定）

- **A. 缝编码 → 轴线编号映射（已定，2026-09-08）：双轨存储 + 导出时选择显示**。数据层每条轴线保留缝编码 `id`（主键）+ 可选字段 `gb_no`；`gb_no` 缺省时自动推导——沿 X 的线（CAO F/B、TUAN）按国标用大写字母从下至上（南=A，跳过 I/O/Z），沿 Y 的线（JIAN、CAO L/R）用阿拉伯数字从左至右（西=1）；显式 `gb_no` 覆盖自动值。图纸编号圆显示 GB 编号，图框内附「编号 ↔ 缝编码」对照表，学术信息零丢失；`model_spec.json`/CSV 两列并存（`seam_id` + `gb_no`）。
- **B. b 的取值（已定，Phase 1 实施）：b=0.7mm**（0.7/0.35/0.18）；若未来默认 A3 幅面再评估升 b。
- **C. 标题栏简化程度（已定，Phase 1 实施）：仅 图名/图号/比例/日期/编码体系版本**，无签字区/会签栏。
- **D. 图名字体（已定，2026-09-08）：嵌入 FandolFang-Regular**（长仿宋风格，GPL + 字体例外，可再分发；OTF 经 cu2qu 转为 TTF 存于 `assets/fonts/`，PDF 子集嵌入——任何阅读器显示一致）。回退：缺字体文件时用 STSong-Light（CID 不嵌入）。
