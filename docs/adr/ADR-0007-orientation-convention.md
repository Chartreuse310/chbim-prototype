# ADR-0007：朝向与坐标约定（坐北朝南，方向字母以建筑自身为基准）

状态：已采纳日期：2026-09-07

## 背景

V1 初版的符号表按"看图者视角"解释方向字母（`_SIGN_XRUN = {F:+1, B:-1, R:-1}`），导致平面图（北在上）中 `CAO_Fo`（前槽缝）出现在北侧、`CAO_Ro` 被当作面阔走向的线——与营造惯例冲突。此外该表中 L 无定义，`CAO_Lo` 会静默解析为 0。

## 决策

1. **坐北朝南**为默认朝向；方向字母以**建筑自身朝向**为基准，而非看图者：
   - `F` = 前 = 南；`B` = 后 = 北；`L` = 建筑左手 = 东；`R` = 建筑右手 = 西
   - 平面图绘制时北在上，因此图面上 L/R 与看图者的左右相反
2. 坐标系：`+X` = 东（面阔向右），`+Y` = 北（进深向上）。
3. **CAO 的走向由方向字母决定**：F/B 线沿 X（定位 y）；L/R 线沿 Y（定位 x）。外圈檐柱对应四条槽缝：`Fo`（南）/`Bo`（北）/`Lo`（东）/`Ro`（西）。
4. JIAN 恒沿 Y；TUAN/TUANJIAN 恒沿 X；FU/PUZUO/TIAO 未定义。
5. 符号表按定位轴划分：定位 y 用 `{F:-1, B:+1}`；定位 x 用 `{L:+1, R:-1}`。

## 后果

- 正面（南侧）构件在平面图中位于图面下方，与"坐北朝南"读图习惯一致。
- 修正了 `CAO_Lo` 静默归零的隐患。
- 示例数据北行槽缝由 `CAO_Ro` 改为 `CAO_Bo`（数据变更，schema 不变）。
- 未来若支持其他朝向（如东向建筑），以「旋转整个坐标系」实现，不改动字母语义；图案/轴线编号再议。
